# TalentHub frontend

## Запуск

```bash
cd talenthub
npm ci
cp .env.example .env.local
npm run dev
```

`VITE_API_URL` — origin API, по умолчанию `https://lbsuhack.onrender.com`. Для локального бэкенда: `http://127.0.0.1:8001`. После изменения переменной перезапустите Vite. Origin фронтенда должен входить в backend `TRUSTED_ORIGINS`.

```bash
npm run build
npm test
```

Фронтенд хранит только Bearer-токен в sessionStorage. Пользователь, каталоги, заявки и остальные продуктовые данные загружаются из API; локальные демозаписи удалены. При смене аккаунта кэш очищается. Стили и оформление сохранены.

## Совместимость бэкенда

Для всех существующих экранов нужна версия API с миграцией `20261106_0002`: несколько детей, предложения ребёнку, прочтение уведомлений, публичные запросы школ компаниям и школьный справочник с показателями по подтверждённым достижениям.

Изменения бэкенда подготовлены в репозитории lbsuhack, ветка `main`. Фронтенд остаётся в ветке `feat/backend-link-implementation`. До их деплоя на Render новые методы недоступны. Сид запускается отдельно; адрес API не содержит секретов.

Проверены во встроенном браузере входы пяти ролей, восстановление сессии, первый вход, подача/отмена заявки, прочтение уведомлений после перезагрузки, несколько детей, предложения ребёнку, школьные показатели, создание/модерация мероприятия, подтверждение заявки и посещения.
